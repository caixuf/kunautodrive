# 规划速度剖面：ST 图 + DP

> 本文是规划速度剖面的权威说明；[算法栈](ALGORITHM_STACK.md)只保留全栈总览。
> 对应源码：`modules/adas_nodes/st_graph.{h,c}`、`modules/adas_nodes/planning_node.cpp`。
> Python 仿真对照：`tools/speed_planner_sim.py`（11/11 场景全 PASS 后移植到 C）。

## 1. 职责与定位

`planning` 是速度和轨迹的**唯一权威**：行为层提供意图与目标速度，规划层输出
`planning/trajectory` 的速度点；`control` 只跟踪轨迹，`safety_control` 只做安全闸门。

速度剖面由以下实现共同构成：

| 项目 | 位置 | 作用 |
|---|---|---|
| ST 图 + DP 求解器 | `st_graph.{h,c}` | 纯 C 时空网格搜索，无第三方依赖 |
| 接入与轨迹组装 | `planning_node.cpp` | 将路径曲率、灯和障碍物约束组装为输入，并写入轨迹 |
| Python 对照仿真 | `tools/speed_planner_sim.py` | 移植或改参前验证红灯、曲率、跟停、掉头和停走闭环 |

## 2. ST 图算法详解

### 2.1 ST 图表示

ST 图以**弧长 s** 为横轴、**时间 t** 为纵轴，编码"在什么时刻到达什么位置"：

```
t (时间)
│
│  ╲  红灯墙（静止占据，变绿消失）
│   ╲
│    ▓▓▓▓▓▓▓  ← 动态障碍物时空轨迹
│        ╲
│  ──────── ← DP 求得的速度剖面 v(s)
│
└──────────── s (弧长)
```

### 2.2 网格离散化

| 参数 | 值 | 说明 |
|------|-----|------|
| `S_RES` | 1.0m | s 方向分辨率 |
| `V_CAND_STEP` | 0.2 m/s | v 方向离散步长 |
| `S_HORIZON` | min 89m | 视界随最近停点动态扩展 |
| `MAX_GRID` | 90 格 | 视界扩展后的最大格数 |
| `MAX_OBS` | 8 | 本车道 ST 占据障碍物上限 |

候选速度集合：`{0, 0.2, 0.4, ..., v_lim(s)}`，其中 `v_lim(s)` 由静态约束决定。

### 2.3 静态速度约束 v_lim(s)

每个 s 格的速度上限取三项最小值：

```
v_lim(s) = min(
    v_max,                         // 限速（默认 20 m/s）
    0.85 · sqrt(a_lat_max / |κ(s)|),  // 曲率约束（向心加速度）
    v_from_stop_distance(s)        // 制动距离自洽（到停点的距离够不够刹停）
)
```

**曲率约束**：`a_lat = v²·κ`，反解 `v = sqrt(a_lat_max / κ)`。0.85 安全系数
留 ~15% 余量，防止 DP 步长取整 + 闭环瞬时速度略超极限（陆家嘴实测 κ=0.101
时 v=7.2 → a_lat=5.2 超 5.0 上限 → 可行性整帧 invalid）。

### 2.4 ST 占据体

**动态障碍物**：从感知获取本车道前方障碍物的 (s0, v, half_len)，在 ST 图中
生成一条斜带（s = s0 + v·t ± half_len）。

**红灯墙**：在停止线前 `wall_margin`（默认 1.0m）处放置静止占据体。
墙在 `t_red`（变绿时刻）消失。`t_red < 0` 表示一直红（无变绿数据）。

```
红灯墙在 ST 图中 = 从 t=0 到 t=t_red 的竖直占据条
绿灯后占据消失 → DP 可以穿过
```

### 2.5 DP 求解

**状态**：`(s_idx, v_idx)` → 在第 s_idx 格、速度为 v_idx·V_CAND_STEP。

**转移**：从 `(s, v)` 到 `(s+1, v')`，要求：
- `|v' - v| / dt ≤ a_max`（加速度约束，`dt = S_RES / ((v+v')/2)`）
- `v' ≤ v_lim(s+1)`（速度上限）
- `(s+1, v')` 不在任何占据体内

**代价函数**：
```
cost(s, v) = ω1 · (v - v_target)² + ω2 · a²
```
- `ω1 = 1.0`：速度跟踪项（趋向目标速度）
- `ω2 = 2.0`：加速度惩罚项（平滑优先）

**回溯**：DP 填满网格后，从终点（s=horizon）最小 cost 的状态回溯，
得到完整速度剖面 `v_out[0..n-1]`。

### 2.6 输出与使用

```c
// planning_node.cpp 中调用
st_graph_plan(&input, &result);
// 取前视点速度：lookahead_s = 0.3·v0 + 前视距离
int idx = (int)(lookahead_s / STG_S_RES);
double target_v = result.v_out[min(idx, result.n - 1)];
```

## 3. 关键设计决策（仿真验证出的坑）

### 3.1 视界动态扩展

ST 图范围 = `max(50m, 最近停点 + 5m)`。

**问题**：固定 50m 视界时，60m 外的红灯墙无法影响当前速度决策 →
车到 50m 才开始减速，来不及刹停。

**解决**：视界随停点扩展，红灯墙 60m 外也能从 42m 开始压速
（等价旧 C 代码 `brake_dist + 20` 提前触发）。

### 3.2 全局时间 t0

**问题**：使用局部时间（每次重规划 t 从 0 开始），停稳后重规划时
墙的 `t_red` 永远 > 0 → 墙"永远没到变绿时刻" → v=0 闭锁死锁。

**解决**：使用全局时间（`clock_now_us` 转秒），墙变绿时刻是绝对时间 →
变绿后墙消失 → DP 自然穿过 → 车起步。

### 3.3 0.85 安全系数

**问题**：0.95 安全系数 + DP 步长 0.2m/s 取整 + 前视对齐（+0.3·v0 米位移）
→ 发布轨迹在弯心 a_lat 恰超 5.0 → 可行性整帧 invalid。

**解决**：降到 0.85，留 ~15% 余量。陆家嘴弯道 κ=0.101 实测通过。

## 4. 当前约束（全部在 ST 图内统一处理）

- 红绿灯停止线和相位窗口（红灯墙）
- 本车道动态障碍物的时空占据（ST 占据体）
- 路径曲率速度上限（v_lim 曲率项）
- 目标速度、加减速度和制动距离可行性（DP 转移约束）

**不属于规划**：对向车和跨车道决策（行为层）、执行器限幅（控制层）、
安全闸门（safety_control 层）。
