## 5. 已知限制（不是 bug，是设计/约定）

1. **`~/.claude/skills/*` 路径在 CLAUDE.md 里被引用，但本机不存在**（workflow / debugging /
   verification / py-sim-first / vis-3d-rendering / su7-rendering / flowsim-physics）。CLAUDE.md
   文件头加了 ⚠️ 说明以方法论自述为准。
2. **flowsim 非确定性**：墙钟 pacing 无累加器 + 进程级 `rand()`，意味着同一 seed 不一定
   复现同一世界。`min_road_margin_m` 的 baseline 漂移无法排除这条原因。
3. **BEV 是影子模式**（`bev/obstacles` 零订阅者），`ENABLE_ONNX=OFF`，`decode_passthrough()`
   是唯一活路径。一旦接线，回归可能重现（见 docs/UPGRADE_DIRECTION.md §5.2）。
4. **节点单测几乎为零**：40 个 ctest 里只有 1 个测 adas 节点纯逻辑（`adas_nodes_logic_tests`），
   且是副本制。`st_graph.c`（DP 速度规划）、`control_node.cpp`、`behavior_planner_node.cpp`、
   `object_tracker_node.c` 全部零单测。根因：节点纯逻辑都是 `static` 且依赖全局 `g`。
5. **`hw` profile (`config/pipeline_car.json`) 结构性损坏**：3 个悬空订阅使
   `fusion/localization` 永不发布，整条下游饿死（waypoint_follower / control / safety_control
   / data_recorder / learner / model_ota 全部），但 topic_contract gate 跑绿（只校名字不校
   发布者存在性）。
6. **`libflowmond_node.so` 缺 -lz**（undefined symbol: deflate* ×3）——但不在任何 pipeline，
   不影响运行。
