# Xiaomi SU7 display asset

This directory contains the `sm_car` glTF asset from
https://github.com/Yechuanjie/xiaomi-su7, included for KunAutoDrive
visualization with the model author's permission as provided to the project
maintainer.

The asset is loaded by `tools/flowboard/js/models.js` and uses the vendored
Three.js Meshopt decoder. Keep the attribution and permission context with
the files; reuse outside this project requires the model author's permission.
